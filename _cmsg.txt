fix(trips): make Book Now link-vs-label bulletproof

A booking link pasted into the "Button text" field saved into booking_label
with booking_url empty, so the button rendered the raw URL and the in-app
hold ran instead of opening the link.

- Add resolveBooking() helper: if the URL field is empty but the label is a
  link, use it as the link; never render a raw URL as the button text
  (falls back to "Book Now").
- Use it everywhere the trip CTA renders (cards, grid, detail dialog,
  featured spotlight) for consistent behavior.
- Normalize on save in the trip form so future entries self-correct.
- Repaired existing data: moved mis-entered booking URLs into booking_url.
